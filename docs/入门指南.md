## 1. 这个项目在做什么

用**近红外光谱**(1000~2250 nm,每个样本 2501 个波长点)判断纱线/织物样本是**正常**还是**异常**。

流程分三步:

```
读光谱 CSV → 可视化看数据 → 训练模型分类(正常/异常)
```

你手上的代码已经跑通了全流程,你要做的是:**装好环境 → 跑一遍 → 理解 → 改着玩**。

## 3. 从零跑通项目(完整流程)

### 3.1 获取代码

```bash
git clone https://github.com/Lwen1243/time-abnormal-fabric.git
cd time-abnormal-fabric
```

### 3.2 创建虚拟环境并安装依赖

```bash
uv venv .venv --python 3.12        # 创建虚拟环境(只需一次)
uv pip install --python .venv/bin/python -r requirements.txt
```

> Windows 下把 `.venv/bin/python` 换成 `.venv\Scripts\python.exe`。
> 首次装 torch 较大(约 60MB+),耐心等待。

### 3.3 放置数据(数据不在代码仓库里!)

这个项目的原始光谱 CSV **不随代码上传**(文件太多),需要把数据放到指定位置:

```
项目根目录/
└── data/
    ├── 正常数据集/正常数据集/*.csv   ← 正常样本
    └── 异常数据集/异常数据集/*.csv   ← 异常样本
```

目录名和嵌套层级必须一致(`data/正常数据集/正常数据集/`),因为代码按这个路径找文件。

### 3.4 跑第一个可视化(验证环境 OK)

```bash
uv run python src/lings/plot_all_spectra.py
```

成功后会打印类似:

```
正常样本: 6731 条 | 异常样本: 1174 条
✅ 图片已保存: .../outputs/all_spectra_overview.png
```

打开 `outputs/` 目录看生成的图片——**走到这一步,环境就通了。**

常用可视化命令:

| 命令 | 产物 |
|---|---|
| `uv run python src/lings/plot_all_spectra.py` | 全样本叠加总览图 |
| `uv run python src/lings/plot_wavelength_distribution.py` | 每波长分布带图/箱线图/统计 CSV |
| `uv run python src/lings/plot_absorbance_histograms.py` | 指定波长处吸光度直方图 |
| `uv run python src/lings/build_absorbance_3d_html.py` | **可旋转的交互式 3D 密度场**(浏览器打开,推荐) |

### 3.5 训练模型

```bash
uv run python src/lings/train_multi_model.py
```

会用 4 种模型(MLP/CNN/GRU/Transformer)做 5 折交叉验证对比,
结果(准确率、F1、AUC 等 + 模型权重 `.pth`)存在 `outputs/multimodel/`。

## 6. 遇到报错怎么办(排查顺序)

1. **完整读一遍报错最后几行** —— 90% 的问题,最后一行 Traceback 会直接告诉你哪个文件、哪一行、什么错
2. **复制报错去搜索** —— Google/百度 搜报错核心信息(如 `ModuleNotFoundError: No module named 'torch'`)
3. **问 AI 助手** —— 把报错完整粘给 ChatGPT / GitHub Copilot(在 VS Code 里直接用)
4. **检查三件套**:
   - 虚拟环境是否激活(本项目用 `uv run` 前缀,不要省略)
   - 数据目录路径对不对(见 3.3)
   - 依赖是否装全(`uv pip install --python .venv/bin/python -r requirements.txt` 重跑一遍)
5. **Git 相关**:
   - 常用命令小抄:`git pull`(拉更新)、`git add -A && git commit -m "说明"`(提交)、`git push`(推送)
   - 冲突/误删别慌,先 `git status` 看状态,再决定

## 7. 常见问题 FAQ

**Q: `ModuleNotFoundError` 一堆?**
A: 依赖没装进虚拟环境。重跑 3.2 的安装命令,并确认命令带了 `uv run` 前缀。

**Q: `FileNotFoundError: data/正常数据集...`?**
A: 数据没放对位置。目录必须是 `data/正常数据集/正常数据集/`(两层同名)。

**Q: 训练很慢?**
A: 本项目用 Apple Silicon 的 MPS 加速,自动检测。其他机器上 CPU 也能跑,只是慢一些。

**Q: 想改模型结构?**
A: 打开 `train_multi_model.py`,模型类都定义在文件上半部分(`SpectralMLP`、`SpectralCNN_Tuned` 等),改完直接 `uv run python src/lings/train_multi_model.py --models cnn --folds 2 --max-epochs 5` 快速验证。

**Q: 数据改了,可视化/训练要重新跑吗?**
A: 要。可视化脚本和训练脚本都是运行时读取 `data/` 的,重跑对应命令即可。
